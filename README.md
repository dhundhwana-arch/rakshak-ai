# 🚀 Rakshak-AI

Rakshak-AI ek advanced AI-powered application hai jo smart assistance aur automated utility management provide karne ke liye design ki gayi hai.

## 🌟 Features
* **AI Chat Assistant:** Queries aur automation ke liye interactive AI interface.
* **Smart Dashboard:** Real-time data tracking aur history management.
* **Local Database Support:** SQLite integration caching aur chat history ke liye (`rakshak_cache.db`, `rakshak_history.db`).

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI / Uvicorn
* **Database:** SQLite
* **Environment:** Termux / Local Server
